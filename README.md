

# TypeScript Mini Projects

A collection of TypeScript mini projects built to practice programming fundamentals, object-oriented programming, type safety, and error handling.

## Projects

### 01. Expense Tracker
A simple expense tracking project that calculates total expenses using TypeScript.

**File:**
- `expense-tracker.ts` — Defines expense data, calculates totals, and displays expense details.

### 02. Task Manager Pro
A task management project with priorities, status updates, filtering, and statistics.

**File:**
- `task-manager.ts` — Implements task creation, completion, filtering, and statistics using classes and interfaces.

### 03. Quiz App
A multiple-choice quiz application with answer validation and score calculation.

**File:**
- `quiz-app.ts` — Manages questions, checks answers, and calculates quiz results.



## Concepts Practiced
- TypeScript types and interfaces
- Functions, arrays, and objects
- Classes and inheritance
- Generics and type constraints
- CRUD operations
- Error handling and validation
- Async/await and Promises
- ES modules and imports/exports

## Purpose
To strengthen TypeScript skills through practical projects, improve problem-solving, and build a programming portfolio.
